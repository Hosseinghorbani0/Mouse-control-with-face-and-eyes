# Contributing

Thanks for helping improve Face Mouse.

## Local setup

1. Create and activate a virtual environment.
2. Install `requirements.txt`.
3. Run `python -m pytest` and `ruff check .`.

## Pull requests

- Keep changes focused and explain the user-facing result.
- Add or update tests for pure logic changes.
- Do not commit camera captures, credentials, generated caches, or virtual environments.
- Verify the source compiles before opening a pull request.

## Commit style

Use a short, imperative Conventional Commit subject, for example `fix: prevent repeated blink clicks`.
