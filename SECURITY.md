# Security Policy

## Supported versions

Only the latest version on the default branch is actively maintained.

## Reporting a vulnerability

Please do not open a public issue for security-sensitive reports. Contact the repository owner privately through the GitHub profile or repository security contact with:

- A clear description of the issue
- Reproduction steps or a minimal proof of concept
- The affected file and environment
- Any suggested mitigation

This project processes camera frames locally and does not intentionally transmit them. Reports involving unexpected camera, display, or mouse behavior are welcome, especially when they can cause unintended input.
